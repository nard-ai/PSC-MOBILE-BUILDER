About

PSC Mobile Builder - Portable Edition v1.0

A tool for building Android WebView wrapper apps using Expo EAS. This portable version includes embedded Python and Node.js runtimes.

How it works:

  1. Configure your web app URL and app name
  2. Optionally upload a custom icon
  3. Click "Build Android App"
  4. Wait for EAS cloud build to complete (usually 5-10 minutes)
  5. Download your APK
